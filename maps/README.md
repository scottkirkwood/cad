# 3D Nautical & Topographical Maps

A collection of 3D printable, backlit-ready nautical displays, lightboxes, and vector cartography models designed for multi-color 3D printers (e.g., Bambu Lab H2C, X1-Carbon, P1S, A1 with AMS) and CNC routing.

---

## Projects & Map Regions

* [`georgian bay/`](file:///home/scott/20p/cad/maps/georgian%20bay/): **Thirty Thousand Islands (Georgian Bay, Ontario)**
  * Spans from **Longuissa Bay** and **Cognashene** down to **South Bay Cove** and **Beausoleil Island**.
  * Features 414 crisp granite islands, authentic IHO/CHS spar buoys, anchorages, 16-facet nautical compass rose, and an aligned high-resolution satellite imagery layer.
  * Written in pure Go with zero external dependencies, automated unit tests, and OpenSCAD parametric CAD generator.
